# Continental Founders™ — Professional Institutional Website

A production-oriented React + Vite website for Continental Founders™, a nonprofit focused on strategic partnerships connecting universities and institutions across Africa and the United States.

## Principles
- React + Vite
- JSX + pure CSS
- No Tailwind
- No Bootstrap
- No Material UI
- No CSS gradients
- Responsive, accessible, institutional visual language
- Explicit `import React from "react"` in JSX files to eliminate `React is not defined` issues
- Every major component and page has its own CSS file
- Real organization facts are not invented; partner/event/impact data is clearly marked as content-ready where appropriate

## Run
npm install
npm run dev

## Build
npm run build
npm run preview
